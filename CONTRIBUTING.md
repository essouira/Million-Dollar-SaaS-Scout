# Contributing

Thanks for helping improve Million-Dollar SaaS Scout.

The goal is better startup decisions through clearer research, stronger validation and more honest financial reasoning.

## Good contributions

- Improve the discovery or validation workflow.
- Add a reproducible industry research example.
- Clarify scoring criteria.
- Add test prompts and expected quality checks.
- Fix inaccurate instructions or broken paths.
- Improve compatibility with Agent Skills hosts.

## Contribution rules

1. Keep changes focused.
2. Explain the problem the change solves.
3. Cite sources for factual claims.
4. Do not add fabricated market data or customer stories.
5. Keep the skill provider-neutral where possible.
6. Do not claim a feature is tested unless it has been tested.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] Markdown and YAML are valid.
- [ ] Relative links and paths work.
- [ ] Scoring weights still total 100%, if changed.
- [ ] Financial examples are mathematically correct.
- [ ] Facts, estimates and hypotheses remain distinguishable.
- [ ] No secrets, private customer data or credentials are included.
